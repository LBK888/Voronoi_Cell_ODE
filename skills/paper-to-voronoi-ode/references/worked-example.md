# Worked translation and checks

This is a constructed demonstration, **not** a reproduction of a published paper. Its numerical parameters are illustrative.

## Equation-to-code mapping

Consider:

```text
dA_i/dt = alpha / (1 + (B_i/K)^h) - gamma_A A_i
dB_i/dt = k A_i - gamma_B B_i
```

| Equation object | Python representation | Meaning / unit relation |
| --- | --- | --- |
| A_i | Y[i, 0] | concentration of A |
| B_i | Y[i, 1] | concentration of B |
| alpha | params['alpha'] | A concentration / time |
| K | params['K'] | B concentration; makes B/K dimensionless |
| h | params['h'] | dimensionless Hill exponent |
| gamma_A, gamma_B | matching params keys | inverse time |
| k | params['k'] | B concentration / (A concentration × time) |

The complete loadable file is [assets/hill-demo.json](../assets/hill-demo.json). Its units and values are explicitly demonstration assumptions. It illustrates separate parameter, ODE and color scripts, with explicit colorbar metadata.

## Useful limiting cases

- Setting alpha to zero gives A(t)=A(0) exp(-gamma_A t). On this program's Euler grid the discrete result is A_n=A_0(1-gamma_A dT)^n, up to clipping. Use this to verify indexing, sign and units.
- Setting k to zero gives the analogous pure decay for B. Do not remove gamma_B or production terms unless the supplied equation does so.
- At B=0 the A production term must be alpha; at B=K it must be alpha/2. These checks catch missing parentheses and incorrect exponents.
- These two equations have no spatial coupling. A spatial pattern here would come from heterogeneous initialization, an added model term or a numerical issue; identical cells should remain identical.

For a source paper, add its equation numbers and real parameter values to a similar mapping and replace the demonstration assumptions explicitly.

## Spatial extension: state the approximation

If a user explicitly requests normalized contact exchange, add:

```python
neighbors = get_voronoi_neighbors_wo_outer(cell_positions)
for i in range(Y.shape[0]):
    adjacent = neighbors.get(i, {})
    total = sum(adjacent.values())
    if total > 0:
        mean_A = sum(weight * A[j] for j, weight in adjacent.items()) / total
        dY[i, 0] += params['coupling_A'] * (mean_A - A[i])
```

This is normalized graph exchange, not a general conservative tissue PDE discretization. The helper filters infinite/long ridges (default maximum length 2.0); choose geometry and boundaries appropriate to the paper. A uniform A field gives zero exchange, but total unweighted concentration need not be conserved on irregular graphs. Do not use that conservation property as an assumed validation target.

## Run the actual validation helper

From the runtime checkout in PowerShell:

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
.\.venv\Scripts\python.exe .\skills\paper-to-voronoi-ode\scripts\validate_model.py .\skills\paper-to-voronoi-ode\assets\hill-demo.json --halving-check --rtol 0.02
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

The validator checks finite derivative shape, absence of in-place Y mutation, matching labels, color-array shapes, and a real short simulation. Optional halving compares deterministic fixed-cell models at a common physical time, rather than comparing the two different final samples generated by `arange`. Its default short validation grid is 5×5; a full per-cell `init_Y` matrix must therefore match that validation grid or be temporarily replaced by a representative vector in a separate validation config. Never silently edit the delivered scientific initial condition to make the validator pass.

For this example, a preliminary Experiments scan can use X=`alpha` (0.5–4), Y=`gamma_B` (0.1–1), observable B, final spatial mean. A short-time response is not automatically a steady-state response; increase T and compare convergence before interpreting equilibrium regimes. To study initial-condition dependence, select Initial concentration on an axis. This sets Y[:, k] at time zero; it does not impose a maintained extracellular concentration.
