# Voronoi Cell ODE v2026.11.19

- **Experiment 軸**支援五種細胞移動強度，也能搭配模型參數或初始濃度交叉掃描。
- **Experiment 熱圖與 CSV**加入第一段明顯上升的最大斜率、切線起始時間與振盪頻率。每次試驗的 CSV 同時保留最終空間平均。無法解析的動態指標留空。
- **模板驗證**涵蓋隨附的七份模板。心臟模板中，直接受刺激的細胞估得每單位模型時間 0.03987 次振盪，預期值為 0.04000。

Windows x64 使用者可下載 `VoronoiCellODE-2026.11.19-windows-x64.zip`，解壓縮後執行 `VoronoiCellODE.exe`。也可單獨下載 EXE，並將模板 ZIP 解壓縮在同一資料夾。資產的 SHA-256 校驗碼見 `SHA256SUMS.txt`。
