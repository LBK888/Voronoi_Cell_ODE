# Windows standalone release — 2026.11.08

## 下載 / Downloads

- **VoronoiCellODE.exe** — Windows 10/11 64-bit 單檔執行版，雙擊啟動，不需另裝 Python 或 FFmpeg。
- **VoronoiCellODE-2026.11.08-windows-x64.zip** — 同一個 EXE，另含操作說明、paper-to-ODE skill 與第三方授權資訊。
- **SHA256SUMS.txt** — 檔案完整性校驗碼。

第一次啟動需要解壓縮內附函式庫，可能需要稍候。此版本未數位簽章。設定與日誌保存在 `%LOCALAPPDATA%\VoronoiCellODE`，更新程式不會覆寫既有設定。

## 更新內容

- 修正 MP4 缺少 colorbar：影片包含物質標籤，色階依影格更新。
- 單張圖預設匯出可編輯 PDF，另支援 SVG／PNG；結果圖按右鍵可複製目前影格與色條。
- Run 後方新增 Experiments：雙軸參數／物質初始濃度掃描、線性／對數取樣、空間／末段統計、重複試驗與取消。
- 支援 PDF 熱圖、每次試驗的 CSV 及模型設定 JSON 匯出。
- 停用滾輪改變參數、滑桿與下拉選單值，保留設定頁面捲動、鍵盤與按鈕操作。
- 新增 paper-to-voronoi-ode agent skill、公式轉換範例及數值驗證工具。
- 新增可重建的 Windows 打包腳本與封裝後 EXE 冒煙測試。

## Validation

The source regression suite contains 41 tests, including persistent configuration/resource path checks. The build script validates the actual frozen EXE, including UI startup, the Numba spatial helper, ODE simulation, clipboard, colorbar MP4, PDF, Experiments, CSV, Excel, HDF5 and both editors. Python, scientific libraries, Qt and FFmpeg are bundled in the executable.

Use only trusted model scripts: the ODE/color editors execute Python with your user account's permissions. Numerical heatmaps use the same explicit Euler integrator as Run; check timestep/time convergence before scientific interpretation.

See [Windows instructions](https://github.com/LBK888/Voronoi_Cell_ODE/blob/main/docs/windows-release.md) and [Experiments guide](https://github.com/LBK888/Voronoi_Cell_ODE/blob/main/docs/experiments.md).
