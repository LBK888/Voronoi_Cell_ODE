# Voronoi Cell ODE v2026.11.12

- 模板移到 EXE 外。Windows 可攜 ZIP 內附 `templates/`，也可單獨下載模板 ZIP，解壓到 EXE 旁。
- **Templates** 選單支援另存目前模型為模板、開啟 JSON 和瀏覽使用者模板資料夾。將一個模型 JSON 拖到主視窗即可載入，再按 **Run Simulation** 執行。
- **Agent** 選單可啟用本機 CLI，並複製連線說明。CLI 支援列出與檢查模型、單次模擬和雙軸掃描，提供 JSON 報告、CSV 與熱圖 PDF。
- 自行匯入的細胞座標可隨模板保存，供 GUI 與 CLI 重用。

使用 Windows 64 位元時，可下載 EXE 或可攜 ZIP。兩種發行檔都可直接執行，內附 Python 和 FFmpeg。完整的 EXE 與 ZIP 校驗碼見 `SHA256SUMS.txt`。
